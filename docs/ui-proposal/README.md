# NetAssets UI 优化方案与 HTML 演示

打开 `index.html` 即可使用，不依赖网络、安装或构建。浏览器访问 `index.html#plan` 可查看完整方案、实施拆分和当前界面截图。

- 范围：全平台统一风格，重点演示修复业务。
- 页面：工作台、网络资产、修复任务、双栏审核、个人工作台、人员与厂商、优化方案。
- 演示数据为虚构内容；所有业务动作仅修改浏览器当前内存，不连接实际后台。
- “保存视图”仅写入该浏览器 localStorage，刷新会重置业务数据。
- `current/`：本轮采集的现状截图（含本地应用数据，请在对外分享前脱敏）。
- `previews/`：优化方案截图，使用虚构数据。
- 图标使用项目已有 Element Plus Icons，授权见 `ICONS-LICENSE.txt`。

本地 Podman 预览采用独立静态容器与端口，不替换正在运行的 8080 应用。

## 已接入真实前端（2026-10-03）

本轮将确认的方案应用到 Vue 前端：

- 统一导航图标、深蓝侧栏、青绿色主题、表格、卡片、表单与中文组件提示；手机端使用可展开导航。
- 工作台优先展示当前权限内的审核、逾期和填报待办，保留安全治理图表及填报进度。
- 修复任务增加快捷状态视图、可折叠高级筛选、浏览器保存视图、行高切换；选中待审核任务后进入逐项审核。
- 执行人员使用个人任务卡片，显示期限、退回原因及阻塞情况。
- 任务详情集中展示共享材料、当前提交和附件；右侧提供接收、提交或审核操作，保留材料历史、版本对比、沟通和申请记录。
- 通过审核前需确认已核对材料；队列切换会清空上项意见和勾选状态。
- 资产列表聚合名称与访问标识、系统与组织；低频字段可展开，归档、删除及历史收纳到“更多”。批量操作仅在选中后显示。
- 人员页强调系统授权、有效期及临期状态，补充空状态引导。

实现与原型的边界：真实角色来自登录权限，页面不提供演示角色切换；数据、附件及审批使用已有后端接口。修复任务的保存视图目前保存在当前浏览器，按用户、工作组织及执行/管理入口隔离，尚不跨设备同步。其他模块沿用现有功能并统一基础样式。本轮不新增数据库迁移。

`implemented/` 保存隔离环境的真实页面截图及布局检查结果；截图中的测试记录不代表正式业务数据。

## 列表布局修订（2026-10-03）

针对右侧操作栏留白过大、主列表需要横向拖动的问题，本轮检查了 18 个列表入口及主标签页。原布局的问题是各列最小宽度相加超过内容区，操作栏又按按钮最多的行预留 190～250px；完成状态只有一个按钮也占用相同宽度。

### 统一规则

- 多项操作使用 88px 的固定操作列，点击“操作”打开按钮面板；仅一项操作时直接显示按钮，没有可操作项时不出现空面板。原有权限、禁用条件、请求处理及危险操作确认继续生效。
- 操作面板使用原生按钮和链接，打开后聚焦首个可用操作，Escape 关闭并返回触发按钮；导出格式和备份文件入口直接展示，不再套第二层菜单。
- 名称、编号、归属等相关信息合并为主次两行；状态、严重程度、期限保留独立展示。数据不会因为合并列而从页面消失。
- 常用桌面宽度（1280、1440px）下默认主列表无需横向拖动；扩展字段、手机端以及详情中的大量快照/差异字段仍允许在表格内部横向查看。
- 填报模式的网络资产沿用精简默认列，“更多字段”可主动展开；已纳入任务的提示放回状态列。

### 页面调整

| 页面 | 调整 |
| --- | --- |
| 安全测试、测试申请 | 名称与编号合并，申请系统与组织合并；按状态显示紧凑操作入口 |
| 安全工单及两个标签页 | 合并发现数量、测试来源、处理结果；修复进度只列有数量的阶段 |
| 业务系统、网络资产及填报草稿 | 名称与标识合并；系统数据安全属性聚合，资产扩展字段主动展开 |
| 用户、组织 | 用户任职与角色、组织名称与编码聚合；统一操作入口 |
| 修复任务、人员与厂商 | 微调主列宽度，人员多操作收纳，单项下一步直接保留 |
| 填报任务 | 任务和组织行操作收纳，导出格式在同一面板直接选择 |
| 待确认资产、质量整改 | 处理说明回到状态/资源列，多项状态操作收纳 |
| 数据治理、巡检历史 | 规则列宽重新分配；命中总数与错误/警告数量聚合 |
| 导出任务、审计日志 | 文件大小归入导出内容，操作人和组织聚合 |
| 备份、回收站 | 备份动作与下载文件统一收纳；回收站保留单个恢复入口 |
